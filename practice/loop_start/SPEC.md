# 비품 대여함 SPEC

총무팀 비품(노트북·모니터)을 날짜 단위로 빌려 주는 서비스. 이 문서가 "끝났다"의 기준이다.

## 1. 용어
- 대여 기간: 시작일~종료일, 두 날짜 모두 대여일에 포함 (예: 12/10~12/12 = 3일)
- 반납 건: status가 returned인 대여. 이미 돌려받은 장비
- 장비: NB-01, NB-02, MON-01 (장비 1개 = 1대)

## 2. 입력과 출력
- 입력: `{ item, user, start, end }` (날짜는 YYYY-MM-DD)
- 출력: `{ status, loan | error }`
  - 201: 승인, loan 반환, 대여 목록에 추가
  - 400: 날짜 오류 (`bad_dates`) · 기간이 7일을 넘음 (`too_long`)
  - 404: 없는 장비 (`unknown_item`)
  - 409: 기간 겹침 (`overlap`)

## 3. 현재 합격 기준 (tests/base.test.js)
| 번호 | 기준 |
|---|---|
| AC-1 | 정상 신청은 201과 대여 정보를 돌려준다 |
| AC-2 | 승인되면 대여 목록에 추가된다 |
| AC-3 | 없는 장비는 404 |
| AC-4 | 종료일이 시작일보다 빠르면 400 |
| AC-5 | 날짜 형식이 틀리면 400 |
| AC-6 | 다른 장비는 같은 기간에도 빌릴 수 있다 |
| AC-7 | 겹치지 않는 다른 기간은 빌릴 수 있다 |
| AC-8 | 시작일이 기존 대여 기간 안에 들면 409 |

## 4. 구조 규칙
- 판정 로직은 `src/loan.js`에만 둔다
- 기존 기준 테스트(`tests/base.test.js`)는 고치지 않는다
