## 끝나고 답할 질문
1. 초록불이 약속하는 것과 약속하지 않는 것은?
   - 약속하는 것: 내가 적어 둔 기준(AC-1~13 · 깨기 1~8)은 지켜진다. 약속하지 않는 것: 기준에 없는 경우. 1-1에서 8개 초록불인데 겹쳐 빌려 가는 사고가 났던 것처럼.
2. 루프가 대신 잡아 준 것은?
   - 구현 전 빨간불 4개(AC-9·10·11·13)로 고칠 곳을 정확히 짚어 줌 · reviewer가 "테스트가 오류 이름을 안 본다"는 빈틈을 찾음 · 깨기 테스트가 "겹침을 너무 넓게"와 "일수 +1 빠뜨림" 실수를 잡음
3. 내 기준에 없어서 못 잡은 것은?
   - 같은 사람이 7일씩 이어서 빌리면 상한을 피해 감(FB-3 "한 달씩 빌려 감"이 그대로 가능) · 기간도 길고 겹치기도 하면 어느 오류를 먼저 알릴지 · 신청자 이름이 비어도 승인됨. 모두 테스트는 초록불이다.
4. 내 업무에서 "끝났다"의 기준을 쓰는 사람은 누구인가?
   - 나(일을 맡기는 사람). AI는 기준을 지키는 쪽이고, 기준이 비면 품질도 빈다.
